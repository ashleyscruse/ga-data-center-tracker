Drawdown Georgia, Phase 5

Counting Georgia's Data Centers, County by County

Ashley Scruse, PhD · Morehouse College · October 2026

Summary

This project counted data centers in all 159 Georgia counties so the results could be added to the Drawdown Georgia Solutions Tracker. It found at least 128 data centers in 34 counties. It also recorded which counties have passed local rules about data centers. All of the data, code, and methods are public.

Background

The Drawdown Georgia Solutions Tracker, run by a team at Georgia Tech led by Dr. Marilyn Brown, measures how each Georgia county is adopting climate solutions, such as utility-scale solar. Every measure in the Tracker is reported by county.

This project was Phase 5 of Drawdown Georgia's work. Its goal was to build a county-level measure of data centers that fits the Tracker's format. Reported this way, data center counts can be compared with the Tracker's electricity solutions in the same counties.

For this project, a data center is a building made mainly to hold computers and data storage at a large scale. Server rooms inside other kinds of buildings do not count.

Data Sources

The project used only free, public sources.

  1. State air permits. Data centers keep diesel generators for backup power. Georgia's Environmental Protection Division (EPD) must permit those generators. Each permit shows the county and the date it was issued.
  2. Georgia Tech's data center map. Georgia Tech's Energy Policy and Innovation Center maps data centers across the state. Each one is marked as operating, under construction, or planned. The center also tracks which counties have passed data center rules (ordinances) or temporary pauses on new projects (moratoria).
  3. Campus data centers. Some universities run their own data centers. These were added by hand from public announcements.
  4. Announced projects. Projects that have been publicly announced but do not appear in any other source yet. These were also added by hand.

Every facility added by hand has a public source link in the dataset.

Results

Permitted data centers. 38 data centers hold state air permits, across 11 counties. Fulton County has 16 and Douglas County has 10. By the year of their first permit: 15 through 2021, 3 in 2022, 2 in 2023, 4 in 2024, 7 in 2025, and 7 in the first half of 2026.

Mapped data centers. Georgia Tech's map shows 123 data centers in 30 counties: 73 operating, 16 under construction, and 34 planned.

Campus and announced data centers. 3 campus data centers in 2 counties, and 1 announced project: Project Camellia, a planned campus in Effingham County.

Statewide total. At least 128 data centers in 34 counties. The total is given as a range, from 128 to 164, because the sources cannot always be matched building by building. Georgia Tech's map shows locations but not names or addresses, so a permitted building cannot always be matched to a point on the map. The lower number assumes every permitted building is also on the map.

Local rules. 13 counties have passed a data center ordinance. 10 counties have passed a moratorium at some point, 11 in total. None of the moratoria were still in effect when the data was collected. 20 counties have at least one data center and no ordinance or moratorium. 4 counties have rules but no data center.

Comparison With Science for Georgia

Drawdown Georgia's recent guide to data centers cites a map by Science for Georgia. That map was compared with this dataset. Science for Georgia lists 188 active data centers in 43 counties. Most of Georgia Tech's mapped data centers match a Science for Georgia location. The comparison found one large project missing from this project's sources, Project Camellia in Effingham County, and it was added.

Limitations

This method only counts data centers that appear in a public record: a state air permit, Georgia Tech's map, or a published announcement. It misses facilities that have not filed for a permit, that run generators too small to need one, or that are not on the map. Some data centers the automated sources missed were added by hand, each with a public source. Others are likely still missing, so 128 is a minimum.

The local rules show what county governments did. They do not show what residents said at meetings or in public comments. Collecting that is a possible next step.

Data Availability

The dataset, the code that builds it, and the full methodology are at github.com/ashleyscruse/ga-data-center-tracker. Anyone can rerun the code to rebuild the dataset or update it as new permits are issued.
